## What's tracked

Everything listed in `DynamicContent.json` for each version, plus the core configs:

- **Core:** `DynamicContent.json`, `GameConfigs.json`, `GameConfigsDS.json`
- **Game data:** catalog, tomes and rifts archives, events, bloodweb rules, tunables and more (JSON)
- **Localized text:** EULA, consents, news and other text in every language
- **Images:** banners and other artwork served from the CDN
